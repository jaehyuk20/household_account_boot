# 모아봐요 가계부

픽셀 섬 위에서 수입과 지출을 기록하는 웹 가계부입니다. 이메일이나 Google 계정으로 로그인하면 기록이 계정마다 따로 저장되고, 어느 기기에서든 같은 기록을 이어서 볼 수 있습니다. 다람쥐 토리가 말풍선으로 이번 달 살림을 알려 주고, 기록할 때마다 동전이 날아가고 숫자가 굴러갑니다.

- 화면: GitHub Pages (정적 웹 호스팅)
- 로그인과 기록 저장: Firebase Authentication + Cloud Firestore (무료 요금제로 충분합니다)

## 기능

- **로그인**: 이메일·비밀번호 회원가입과 로그인, Google 계정 로그인, 비밀번호 재설정 메일, 로그아웃
- **기록하기**: 휴대폰에서는 화면 아래 나뭇잎(+) 버튼, PC 화면에서는 내역 칸의 `기록하기` 버튼으로 기록 시트를 엽니다. 지출/수입, 금액(`+1천`·`+1만` 같은 빠른 버튼 포함), 카테고리, 날짜, 메모를 입력합니다. 달력에서 기록이 없는 날을 누르면 그 날짜로 바로 기록할 수 있습니다.
- **카테고리**
  - 지출 12가지: 식비, 카페·간식, 생활·마트, 쇼핑·미용, 교통·차량, 주거·통신, 의료·건강, 문화·여가, 여행·숙박, 교육, 경조·선물, 기타
  - 수입 8가지: 월급, 상여금, 부업·알바, 용돈, 금융·투자, 중고판매, 환급·캐시백, 기타
- **이번 달 요약**: 남은 돈(이번 달 수입 − 지출), 수입·지출 합계, 수입 대비 지출 비율 막대, 그리고 처음 기록부터 이어지는 **현재 잔액**
- **내역**: 날짜별로 묶어 보여 주고, 기록마다 **그 기록 직후의 잔액**을 함께 보여 줍니다. 내역이 길어져도 화면 전체가 아니라 내역 칸 안에서만 스크롤되고, 오른쪽 위 `크게 보기` 버튼을 누르면 내역이 화면 가득 펼쳐집니다(`Esc`나 같은 버튼으로 닫기). 항목을 누르면 고치거나 지울 수 있고, 지운 기록은 알림의 `되돌리기`로 되살릴 수 있습니다.
- **달력·통계**
  - 달력: 날짜마다 그날 들어온 돈(+)과 쓴 돈(−)을 보여 줍니다. 칸이 좁으면 `15.2만`처럼 줄여 쓰고, 정확한 금액은 내역에 있습니다. 기록이 있는 날을 누르면 그날 내역으로 갑니다. 달력 아래에는 하루 평균 지출, 가장 많이 쓴 날, 지출 없는 날 수가 나옵니다.
  - 원그래프: 지출·수입을 카테고리별로 보여 줍니다. 큰 다섯 개에 색을 주고 나머지는 회색 `그 외`로 묶으며, 범례에 카테고리마다 건수·금액·비율이 모두 나옵니다.
- **PC 화면**: 창 너비가 1200px 이상이면 요약·토리 말풍선·내역·달력·지출/수입 원그래프를 스크롤 없이 한 화면에 펼칩니다. 오른쪽 위 휴대폰 모양 버튼을 누르면 휴대폰과 같은 한 줄 배치로 돌아가고, 고른 배치는 그 브라우저에 기억됩니다.
- **실시간 반영**: 같은 계정으로 다른 기기나 탭에서 기록하면 열려 있는 화면에도 바로 반영됩니다.
- **낮/밤 풍경**: 오른쪽 위 버튼으로 바꿀 수 있고, 처음에는 기기 설정(라이트/다크)을 따릅니다.

## 잔액은 이렇게 셉니다

- **현재 잔액** = 시작 잔액 + 오늘까지의 모든 수입 − 모든 지출. 달이 바뀌어도 이어서 셉니다(통장처럼). 미래 날짜로 적은 기록은 그날이 되면 반영됩니다.
- **기록마다 보이는 잔액**은 그 기록이 반영된 직후의 잔액입니다. 날짜순으로 쌓고, 같은 날의 기록은 입력한 순서대로 쌓습니다.
- **시작 잔액**은 처음에 0원입니다. 요약 카드의 `맞추기`를 누르고 지금 실제로 가진 돈(통장과 지갑을 합친 금액)을 적으면, 기록은 그대로 두고 그 금액에 맞게 시작 잔액을 거꾸로 계산해 저장합니다.

## 배포하기

처음 한 번만 하면 됩니다. Firebase 프로젝트는 사이트를 운영하는 사람의 Google 계정으로 만듭니다.

### 1. Firebase 연결하기

1. [Firebase 콘솔](https://console.firebase.google.com)에서 **프로젝트 만들기**를 누릅니다. Google 애널리틱스는 꺼도 됩니다.
2. 프로젝트 개요 화면에서 **웹 앱 추가(`</>`)** 를 누르고 앱 이름을 정합니다. 화면에 나오는 `firebaseConfig` 값을 [`js/config.js`](js/config.js)에 그대로 옮겨 적습니다.
3. 왼쪽 메뉴 **Authentication → 시작하기 → 로그인 방법**에서 **이메일/비밀번호**와 **Google**을 사용 설정합니다.
4. **Authentication → 설정 → 승인된 도메인**에 `jaehyuk20.github.io`를 추가합니다. (Google 로그인 창이 이 주소에서 열리려면 필요합니다.)
5. 왼쪽 메뉴 **Firestore Database → 데이터베이스 만들기**를 누릅니다. 위치는 `asia-northeast3 (서울)`, 시작 모드는 **프로덕션 모드**를 고릅니다.
6. Firestore의 **규칙** 탭에 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여 넣고 **게시**합니다.
7. **색인 만들기**: 잔액은 서버에서 합계를 세는데, 이때 색인이 하나 필요합니다. Firestore의 **색인** 탭 → **복합** → **색인 추가(Create index)** 를 누르고 아래처럼 입력한 뒤 **만들기**를 누릅니다. 만드는 데 몇 분 걸립니다.
   - 컬렉션 ID: `entries`
   - 필드 1: `date` — 오름차순
   - 필드 2: `delta` — 오름차순
   - 쿼리 범위: **컬렉션**

   (Firebase CLI를 쓴다면 `firebase deploy --only firestore`로 [`firestore.rules`](firestore.rules)와 [`firestore.indexes.json`](firestore.indexes.json)을 한 번에 올릴 수 있습니다.) 색인이 없으면 화면에 "잔액 계산에 필요한 색인이 아직 없어요" 알림이 뜨고, 브라우저 개발자 도구 콘솔의 오류 메시지에 색인을 바로 만드는 링크가 나옵니다.

`js/config.js`에 들어가는 값은 공개되어도 괜찮은 값입니다. 다른 사람의 기록을 읽거나 쓰지 못하게 막는 일은 6번의 보안 규칙이 맡습니다.

### 이미 배포한 사이트를 이번 버전으로 올릴 때

잔액 기능이 들어가면서 저장 형식이 바뀌었습니다. 새 화면을 열기 **전에** 아래 두 가지를 먼저 해 주세요.

1. 위 6번처럼 바뀐 [`firestore.rules`](firestore.rules)를 다시 붙여 넣고 **게시**합니다. 예전 규칙 그대로면 새 기록 저장과 잔액 계산이 권한 오류로 막힙니다.
2. 위 7번의 색인을 만듭니다.

예전에 남긴 기록은 각자 다음 로그인 때 한 번 자동으로 새 형식(`delta` 필드)으로 고쳐집니다.

### 2. GitHub Pages 켜기

1. GitHub 무료 요금제에서는 **공개 저장소**만 Pages를 쓸 수 있습니다. 저장소가 비공개라면 **Settings → General → Danger Zone → Change repository visibility**에서 Public으로 바꿉니다. (GitHub Pro 이상이면 비공개로 둬도 됩니다.)
2. **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로 두고, 이 사이트 파일이 있는 브랜치와 `/ (root)` 폴더를 고른 뒤 **Save**를 누릅니다.
3. 잠시 뒤 `https://jaehyuk20.github.io/household_account_boot/` 에서 열립니다.

## 데이터와 개인정보

- 기록은 Firestore의 `users/{사용자 ID}/entries`에 저장되고, 보안 규칙으로 **본인만** 읽고 쓸 수 있습니다. 다른 사용자는 남의 기록을 볼 수 없습니다.
- `users/{사용자 ID}` 문서에는 시작 잔액(`openingBalance`)과 저장 형식 버전(`schema`)만 저장합니다. 기록마다 있는 `delta`는 수입이면 `+금액`, 지출이면 `−금액`이며, 보안 규칙이 금액과 맞는지 확인합니다.
- 단, Firebase 프로젝트를 가진 **운영자는 콘솔에서 모든 기록을 볼 수 있습니다.** 다른 사람에게 사이트를 알려 줄 때 이 점을 함께 알려 주세요.
- 로그아웃하면 그 탭에 남아 있던 기록도 메모리에서 지웁니다.
- Firebase 무료 요금제(Spark)는 Firestore 기준 하루 읽기 5만 건, 쓰기 2만 건, 저장 1GiB까지입니다. 친구 몇 명이 쓰기에는 충분합니다. 화면은 보고 있는 달의 기록만 불러오고, 지난 잔액은 서버의 합계 기능(기록 1,000건당 읽기 1건)으로 셉니다.
- 계정 삭제 화면은 없습니다. 요청이 오면 운영자가 Firebase 콘솔의 Authentication과 Firestore에서 지울 수 있습니다.

## 로컬에서 실행하기

ES 모듈과 Firebase를 쓰기 때문에 `index.html`을 파일로 바로 열면 동작하지 않습니다. 로컬 서버로 띄워 주세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속 (js/config.js에 Firebase 설정이 필요합니다)
```

Firebase 프로젝트 없이 시험해 보려면 [Firebase 에뮬레이터](https://firebase.google.com/docs/emulator-suite)를 씁니다. (Java가 필요합니다.)

```bash
npx firebase-tools emulators:start --only auth,firestore --project demo-moa
# 다른 터미널에서 python3 -m http.server 8000 후
# http://localhost:8000/?emulator 접속
```

`?emulator`는 `localhost`에서만 동작합니다. 이때는 `js/config.js` 대신 데모 프로젝트(`demo-moa`)를 쓰므로 실제 Firebase 프로젝트에는 닿지 않습니다.

## 파일 구성

```
index.html        화면 구조 (시작 → 로그인 → 가계부)
css/style.css     낮/밤 색 토큰, 계단식 픽셀 모서리, 레이아웃, 키프레임
js/config.js      Firebase 웹 앱 설정 (운영자가 채움)
js/cloud.js       Firebase 인증·Firestore 연결 (gstatic CDN의 Firebase JS SDK 12.19.0)
js/store.js       카테고리 정의, 달마다 실시간으로 받는 기록 저장소, 이어지는 잔액 계산
js/app.js         화면 동작(로그인, 기록 시트, 내역, 달력, 원그래프, 넓은 화면 배치, 잔액 맞추기, 알림, 계정 메뉴)
js/fx.js          스프링 이징, 오도미터, 타자기, 픽셀 파티클, 섬 풍경
js/sprites.js     픽셀 그림(아이콘, 토리, 풍경)과 SVG 렌더러
firestore.rules   본인 기록만 읽고 쓰게 하는 보안 규칙
firestore.indexes.json  잔액 합계에 쓰는 복합 색인 (entries: date, delta)
firebase.json     규칙·색인 배포와 에뮬레이터 설정 (Firebase CLI용)
fonts/            갈무리(Galmuri) 픽셀 글꼴
```

모든 아이콘과 캐릭터는 이 프로젝트를 위해 새로 그린 픽셀 그림이며, 별도 이미지 파일 없이 코드 안의 픽셀 격자로 그립니다.
