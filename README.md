# 모아봐요 가계부

픽셀 섬 위에서 수입과 지출을 기록하는 웹 가계부입니다. 다람쥐 토리가 말풍선으로 이번 달 살림을 알려 주고, 기록할 때마다 동전이 날아가고 숫자가 굴러갑니다.

## 기능

- **기록하기**: 화면 아래 나뭇잎(+) 버튼을 누르면 기록 시트가 열립니다. 지출/수입을 고르고 금액, 카테고리, 날짜, 메모를 입력합니다. `+1천`, `+1만` 같은 버튼으로 금액을 빠르게 더할 수 있습니다.
- **카테고리**
  - 지출 12가지: 식비, 카페·간식, 생활·마트, 쇼핑·미용, 교통·차량, 주거·통신, 의료·건강, 문화·여가, 여행·숙박, 교육, 경조·선물, 기타
  - 수입 8가지: 월급, 상여금, 부업·알바, 용돈, 금융·투자, 중고판매, 환급·캐시백, 기타
- **이번 달 요약**: 남은 돈(수입 − 지출), 수입·지출 합계, 수입 대비 지출 비율 막대
- **내역**: 날짜별로 묶어 보여 주고, 항목을 누르면 고치거나 지울 수 있습니다. 지운 기록은 알림의 `되돌리기`로 되살릴 수 있습니다.
- **통계**: 이 달의 지출·수입을 카테고리별 금액, 건수, 비율로 보여 줍니다.
- **달 이동**: 요약 카드 위쪽 화살표로 지난 달과 다음 달을 오갑니다.
- **낮/밤 풍경**: 오른쪽 위 버튼으로 바꿀 수 있고, 처음에는 기기 설정(라이트/다크)을 따릅니다.
- 처음 열면 둘러보기용 **예시 기록**이 보입니다. `예시 지우기`를 누르면 빈 가계부로 시작합니다.

## 움직임

- 나뭇잎 버튼에서 원이 퍼지며 시트가 열리는 전환, 스프링 물리로 계산한 이징(CSS `linear()`)
- 숫자가 한 자리씩 굴러가는 잔액 오도미터, 금액 입력 시 튀어 오르는 숫자
- 수입을 기록하면 동전이 잔액으로 날아가고, 지출을 기록하면 동전이 튀어 나갑니다. 지울 때는 연기가 펑 터집니다.
- 말풍선 타자기 효과와 말하는 동안 입을 움직이는 토리
- 계절에 맞춰 떨어지는 단풍잎·꽃잎·눈, 흘러가는 구름, 흔들리는 나무, 스크롤에 따라 움직이는 하늘
- 기기에서 **동작 줄이기**를 켜 두면 장식 움직임을 끄고 바로 결과를 보여 줍니다.

## 실행

빌드 과정이 없는 정적 페이지입니다. `index.html`을 브라우저로 열면 바로 동작합니다.

로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages 같은 정적 호스팅에 그대로 올려도 됩니다.

## 데이터 저장

기록은 브라우저의 `localStorage`(`moa-ledger/v1` 키)에 저장됩니다. 서버로 보내지 않으며, 같은 브라우저에서만 이어서 볼 수 있습니다. 브라우저의 사이트 데이터를 지우거나 시크릿 창을 닫으면 기록도 사라집니다.

## 파일 구성

```
index.html        화면 구조
css/style.css     낮/밤 색 토큰, 계단식 픽셀 모서리, 레이아웃, 키프레임
js/sprites.js     픽셀 그림(아이콘, 토리, 풍경)과 SVG 렌더러
js/store.js       카테고리 정의, 기록 저장·불러오기, 예시 기록
js/fx.js          스프링 이징, 오도미터, 타자기, 픽셀 파티클, 섬 풍경
js/app.js         화면 동작(기록 시트, 내역, 통계, 알림)
fonts/            갈무리(Galmuri) 픽셀 글꼴
```

모든 아이콘과 캐릭터는 이 프로젝트를 위해 새로 그린 픽셀 그림이며, 별도 이미지 파일 없이 코드 안의 픽셀 격자로 그립니다.
